# Polish product terminology

| Polish term | Meaning in this application |
| --- | --- |
| czynsz najmu | rent paid to the owner |
| czynsz administracyjny | building/administration charge |
| media | utilities such as water, power, gas and internet |
| kaucja | refundable deposit |
| prowizja | agency commission |
| koszt wejścia | move-in cost |
| koszt miesięczny | normalized monthly cost |
| ogłoszenie | rental listing or advertisement |
| oględziny | property viewing |
| dojazd | commute |
| ranking | user-defined ordering of candidate listings |
